1. **Create Popup Form in AdminPanel:**
   - In `AdminPanel.jsx`, update the `Offers` tab to include a new section to create/manage a "Popup Ad".
   - The popup ad data should include:
     - `isActive` (boolean)
     - `heading` (text)
     - `description` (text)
     - `imageUrl` (text)
     - `targetUrl` (text - URL path to navigate to when clicked, e.g., `/shop`, `/product/123`)
     - `targetPage` (dropdown/select - where should the popup appear: e.g., 'All Pages', 'Home', 'Shop')
   - Save this data to `settings/popupAd` in Firebase.
2. **Create Popup Component:**
   - Create a new component `src/components/PopupAd.jsx`.
   - It will fetch `settings/popupAd` from Firebase when mounted (or use context if easier).
   - Only show the popup if:
     - It's active.
     - The user hasn't closed it in the current session (`sessionStorage` check).
     - The current path matches the selected `targetPage` (or 'All Pages').
   - When clicked, it should navigate to the `targetUrl`.
   - It should have a close 'X' button that saves to `sessionStorage` and hides the popup.
3. **Integrate Popup Component:**
   - Add `<PopupAd />` to `App.jsx` inside the `<Router>` (so it can use `useLocation` and `useNavigate`).
4. **Testing & Pre-commit:**
   - Ensure the app builds, the admin form saves correctly, and the popup renders when conditions are met.
   - Run tests/linters.
